# Aplikasi Product Manager

Aplikasi pengelolaan data produk berbasis PHP & MySQL.

## Fitur
1. CRUD Produk (Tambah, Lihat, Edit, Hapus)
2. Validasi Input & Mencegah Duplikasi
3. Keamanan PDO, Anti-XSS (htmlspecialchars), dan CSRF Token pada Delete
4. Tampilan Responsif dengan Flexbox
5. Fitur Pencarian Produk
